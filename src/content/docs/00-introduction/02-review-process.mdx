To ensure the objectives of correctness and completeness, a multi-stage review process is proposed. The stages are: preparation, prereview request, prereview response, review request, review response, and approved.

<Image src={reviewProcess} alt="Business Process Model of the review process" />

1. Preparation
   1. The process starts with drafting and reviewing the proposal.

2. Prerreview Request Phase
   1. A prereview request is sent out for initial feedback.
   2. The system waits for a response by a deadline. If the deadline is missed, a prereview reminder is sent.

## Prerreview Response Phase

- Upon receiving a prereview response, the response is analyzed:
  - If a change is required with resubmission, the process loops back to process the change request and sends another prereview request.
  - If a change is required but resubmission is not necessary, the change request is processed and the process moves forward.
  - If no change is needed, the process advances to sending a review request.

## Review Request Phase

- A formal review request is sent.
- The system waits for a response by a deadline, with reminders sent if necessary.

## Review Response Phase

- After receiving the review response, it is analyzed:
- If a change is required with resubmission, the process loops back to process the change request and another review request is sent.
- If a chang® is required without resubmission, the change request is processed and the process proceeds.
- If no change is needed, the process moves to approval.

## Approved Phase

- The process concludes with the document or proposal being approved.

Key Features
• Iterative Feedback Loops: Both prereview and review phases allow for iterative changes, with the possibility to resubmit or process changes without resubmission.
• Automated Reminders: The system sends reminders if responses are not received by the deadline.
• Decision Points: At each response analysis, decisions are made whether to require changes, resubmission, or proceed.
This process ensures thorough review and quality control, with clear steps for feedback, revision, and escalation toward final approval.
