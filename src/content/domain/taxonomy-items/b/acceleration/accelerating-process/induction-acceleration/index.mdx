definition:
  de: Die Induktionsbeschleunigung ist eine Methode zur Beschleunigung geladener
    Teilchen mit Hilfe zeitlich veränderlicher Magnetfelder, wobei die
    beschleunigenden elektrischen Felder durch wechselnde Magnetflüsse erzeugt
    werden. Dieses Prinzip wird in der Regel in Induktionsbeschleunigern
    angewandt, die entweder linear oder kreisförmig aufgebaut sein können.
  en: Induction acceleration refers to a method of accelerating charged particles
    using time-varying magnetic fields, where the accelerating electric fields
    are generated by changing magnetic fluxes. This principle is commonly
    employed in induction accelerators, which can be either linear or circular
    in design.
